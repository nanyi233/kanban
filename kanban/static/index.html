📖 使用帮助

🎯 优先级说明

  • P0 (紧急执行): 低难度 + 高价值，传说中的"低垂果实"，立刻去做！
  • P1 (计划推进): 高难度 + 高价值，战略性项目，需要拆解目标逐步推进。
  • P2 (随缘处理): 低价值/高难度，随缘处理，或者干脆扔进"墓地"。

🌱 成熟度标记

  • 🌱 Seed: 只有一个标题或一句话的初始想法
  • 🌿 Sprout: 有了大概框架，正在萌芽
  • 🌳 Tree: 资料齐备，随时可以开工

🖱️ 操作方式

  • 拖拽: 将卡片拖到不同列来改变优先级
  • 双击: 打开文件或文件夹
  • 右键: 修改项目的成熟度标记
  • 搜索: 使用顶部搜索框快速定位项目
