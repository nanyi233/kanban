# 📋 项目管理看板 (Project Kanban Board)

一个可视化的项目管理看板系统，支持拖拽操作来管理项目优先级。

## 🚀 快速开始

### 方式一：一键启动（推荐）
双击 `start.bat` 文件即可启动。

### 方式二：手动启动
```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动服务器
python app.py

# 3. 打开浏览器访问
# http://localhost:5000
```

## ✨ 功能特性

### 🎯 优先级管理
- **P0 (紧急执行)**: 低难度 + 高价值，立刻去做
- **P1 (计划推进)**: 高难度 + 高价值，拆解目标
- **P2 (随缘处理)**: 低价值/高难度，有空再说

### 🌱 成熟度标记
- **🌱 Seed**: 只有一个标题或一句话的初始想法
- **🌿 Sprout**: 有了大概框架，正在萌芽
- **🌳 Tree**: 资料齐备，随时可以开工

### 🖱️ 操作方式
| 操作 | 功能 |
|------|------|
| 拖拽 | 将卡片拖到不同列来改变优先级 |
| 双击 | 打开文件或文件夹 |
| 右键 | 修改项目的成熟度标记 |
| Ctrl+R | 刷新项目列表 |
| Ctrl+F | 聚焦搜索框 |
| ? | 显示帮助 |

### 🎨 界面特性
- 响应式布局，适配不同屏幕尺寸
- 深色/浅色主题切换
- 流畅的拖拽动画
- 实时搜索和过滤

## 📁 项目结构

```
kanban/
├── app.py              # Flask 后端服务器
├── requirements.txt    # Python 依赖
├── start.bat          # Windows 启动脚本
├── README.md          # 项目说明
└── static/
    ├── index.html     # 主页面
    ├── styles.css     # 样式文件
    └── app.js         # 前端逻辑
```

## 🛠️ 技术栈

- **后端**: Python Flask
- **前端**: HTML5 + CSS3 + JavaScript
- **特性**: 拖拽 API, CSS 动画, Web Audio API

## 📝 注意事项

1. 确保 Python 3.7+ 已安装
2. 服务器启动后会扫描 `D:\BaiduSyncdisk\分享` 目录下的 P0/P1/P2 文件夹
3. 拖拽卡片会实际移动本地文件/文件夹
4. 修改成熟度会重命名文件/文件夹
