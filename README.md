# 📁 项目管理目录架构说明

## 一、优先级分类 (P0/P1/P2)

基于 **价值 vs 难度** 的双轴评估法，将项目分为三个优先级：

| 优先级 | 定义 | 行动策略 |
|--------|------|----------|
| **P0** | 低难度 + 高价值 | 🎯 传说中的"低垂果实"，**立刻去做** |
| **P1** | 高难度 + 高价值 | 📋 战略性项目，需要**拆解目标**逐步推进 |
| **P2** | 低价值 / 高难度 | 🌙 随缘处理，或干脆扔进"墓地" |

---

## 二、颗粒度标记 (Seed/Sprout/Tree)

使用 Emoji 或统一前缀来区分想法的**成熟度**：

| 标记 | 符号 | 含义 | 状态描述 |
|------|------|------|----------|
| **Seed** | 🌱 | 种子 | 只有一个标题或一句话的初始想法 |
| **Sprout** | 🌿 | 幼苗 | 有了大概框架，正在萌芽 |
| **Tree** | 🌳 | 大树 | 资料齐备，随时可以开工 |

### 使用示例

文件夹/文件命名格式：`[标记] 项目名称`

```
🌱 [Seed] 智能家居想法
🌿 [Sprout] 个人博客重构计划
🌳 [Tree] 年度总结报告
```

---

## 三、工作流建议

1. **收集阶段**：新想法先进入 P2，标记为 🌱 Seed
2. **评估阶段**：定期评估 P2 项目，有价值的提升到 P1 或 P0
3. **培育阶段**：随着想法成熟，更新标记 🌱 → 🌿 → 🌳
4. **执行阶段**：优先处理 P0 中的 🌳 Tree 项目

---

> 💡 **提示**：当你面对 50 个想法不知道先做哪个时，用这套系统快速筛选出真正值得投入时间的项目！
